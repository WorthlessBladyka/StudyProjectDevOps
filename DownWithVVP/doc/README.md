# Задача
Построить архитектуру по LEMP стеку.
- Linux
- Nginx (репликая, веб-сервер)
- Postgresql (хранит таблицу голосов)
- Python (логика отправки голоса в базу данных, база данных ищет совпадение по email)

Nginx(рекликация) -> Nginx(веб-сервер) -> Postgresql
